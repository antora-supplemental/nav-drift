= Changelog

== 0.1.4 — hide-page directive

* Recognize `:hide-page:` as synonym for `:hide-from-navtree:` (nav tree omission only; page stays published).

== 0.1.3 — hide-from-navtree directive

* Primary directive `:hide-from-navtree:` (legacy `:page-nav-hidden:` still parses).
* Optional `:navtree-parent:` (legacy `:page-nav-parent:`).

== 0.1.2 — explicit nav-hidden pages

* Honor `:page-nav-hidden:` on pages when `--require-in-nav` is set; report as `nav-hidden-page` (intentional) instead of `page-missing-from-nav`.
* Triage report lists intentional nav-hidden pages separately; `--fail` still only counts actionable findings.

== 0.1.0 — 2026-09-27

* Initial release.
